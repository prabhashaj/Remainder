# Remainder — Development Guidelines

Remainder is a calm, slow-productivity workspace and AI learning companion built with TanStack Start, React 19, Supabase, Vercel AI SDK, and Tailwind CSS.

## Key Principles

- **Calm & Personal UI**: Soft colors, glassmorphism, rounded components, and encouraging micro-copy.
- **AI Specialist Agents**: Specialized agents for tutor, research (Tavily search), curriculum generation, and planning.
- **Multi-Provider AI Gateway**: Configurable via `.env` (`MISTRAL_API_KEY`, `OPENAI_API_KEY`, `OPENROUTER_API_KEY`, `GEMINI_API_KEY`).
